## Highlights

- **The default VM and starting on demand.** Commands that act on one VM, such as `ssh`, `exec`, `app`, `desktop`, `map` and `mount`, may leave the name out. They use the VM of the workspace that contains the current directory, else the only user VM, and say which on stderr; several VMs and no workspace is an error that lists the names. `stop`, `rm`, `compact`, `resize`, `snapshot`, `clone` and `route` still need the name.
  - Inside a workspace, `pvm ssh` starts in the matching guest directory.
  - At a terminal pvm asks before starting a stopped daemon or VM; `--yes` skips the question. Scripts still get the `pvm start` hint.

  See [SKILL.md](../../SKILL.md#default-vm-and-starting-on-demand).
- **Host window frames for `pvm app`.** GTK programs run with `gtk3-nocsd` preloaded, so the host draws their title bar and minimize, maximize and close buttons. On Windows hosts, programs that draw their own frame, such as Electron apps like Claude Desktop, get the host's frame too, above their own top bar. The guest installs `gtk3-nocsd` with Xpra; VMs that already have Xpra get it on the next app start.
- **Chromium apps skip the GPU path.** Programs with Chromium's `v8_context_snapshot.bin` beside them, such as Electron apps and Chrome, start with `--disable-gpu`. The VM has no GPU, and Chromium's software OpenGL is slower than its plain software drawing, so scrolling, hovering and resizing are smoother. A shell script that starts Chromium is not detected; add the flag yourself.
- **Fonts for all major scripts and color emoji.** Golden images install `fonts-noto-core` and `fonts-noto-color-emoji` next to `fonts-noto-cjk`, so Arabic, Hebrew, Indic, Thai and other scripts and emoji no longer show as boxes. This adds about 53 MB to each golden image. It applies to golden images baked from this release on; in existing VMs run `sudo apt install fonts-noto-core fonts-noto-color-emoji`.

## Fixes

- **Silent clipboard.** `pvm app` and `pvm app attach` say on stderr when the VM's clipboard is off, with the `pvm app config` command that turns it on, since copy and paste otherwise just do nothing.
- **Releases and upgrades come from this repository.** `scripts/install.sh`, `pvm upgrade` and the exit deployment steps in SKILL.md point at BitterOrange/pvm.
