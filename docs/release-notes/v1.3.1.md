## Highlights

This release brings the rest of upstream's changes, which this fork's pull request did not contain. Its own history is merged too, so future upstream releases come in with a plain `git merge upstream/master`.

- **Kernel arguments are checked when they take effect.** A VM that boots without the kernel arguments its accelerator needs is stopped and its safe boot state restored, instead of running on the wrong CPU model. The port-map limit of the native Windows backend is now also checked when the gateway's forwards are synced.
- **`pvm desktop` works on older VMs.** A VM started before `pvm.stream` existed, and not restarted since, keeps its desktop on the gateway map and relay path instead of failing; it moves to the stream at its next restart.
- **Any user but root.** The `pvm.stream` targets accepted only uids of 1000 and above. A macOS host gives the VM user its own uid, 501, so `pvm app` and its clipboard now accept any user but root.
- **Stricter stops.** Stopping an app or the app server stops only units that are running and no longer hides other failures, and a corrupt Xpra password file is reported instead of being silently replaced.

## Upgrading

- Nothing to do beyond installing this release. `pvm upgrade` still replaces `pvm.exe` only; PVM Desktop comes with the Windows installer.
