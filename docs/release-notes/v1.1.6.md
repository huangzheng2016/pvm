## Highlights

- **Faster new Windows VMs under WHPX.** New native Windows guests run with `-cpu host` instead of the minimal `qemu64` model, so they see the host CPU and its instruction set extensions (SSE4.x, AES-NI, POPCNT and more) rather than a 2003-era baseline. CPU-bound work such as compression, crypto, compilers and package installs is much faster. XSAVE stays masked (`-cpu host,-xsave`, guest `noxsave`) because WHPX cannot run it reliably, so AVX is not available to the guest. Existing VMs without `noxsave` keep the safe `qemu64` model.
- **Hypervisor Platform detection without administrator rights.** Before probing WHPX, pvm now checks that Windows Hypervisor Platform is enabled and its hypervisor is running, by querying `WHvGetCapability` from `WinHvPlatform.dll`. Unlike `Get-WindowsOptionalFeature`, this works for a standard user, so a per-user install does not wrongly fall back to TCG. `PVM_QEMU_ACCEL=whpx` still forces a WHPX attempt.
- **Smaller default VM size.** New VMs now default to a quarter of the host's logical CPUs (rounded up) and a quarter of host RAM (at least 2 GB), down from all CPUs and half of RAM. A busy guest no longer starves the host, parallel builds are less likely to push the host into swap, and on Windows, where WHPX commits all guest RAM at start, VMs no longer fail to start on hosts with little free memory. This applies on every platform. Existing VMs keep their size. To choose your own, pass `--cpus` and `--mem` to `pvm create`, or set `defaults.cpus` and `defaults.mem_mb` in `~/.pvm/config.yaml`.
- **Windows installers.** Releases ship per-user `pvm_windows_amd64_setup.msi` and `pvm_windows_amd64_setup.exe`. Neither needs administrator rights. Both install `pvm.exe` to `%LOCALAPPDATA%\pvm`, add it to the user `PATH`, include the bundled QEMU runtime, and uninstall from Settings > Apps while keeping VM data under `~/.pvm`. When run interactively, both offer to stop a running pvm before replacing files. See [Windows installers](../../README.md#windows-installers) for details and known limitations.
